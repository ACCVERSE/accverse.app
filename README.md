# ACCVERSE

ACCVERSE is an animal-first digital ecosystem focused on identity continuity, responsibility, and memory.

This repository hosts the public informational website for accverse.app.

The project deliberately avoids virality, engagement-driven mechanics, and content exploitation.
Animals are treated as subjects with persistent identity, while humans act only as representatives.

This website presents the conceptual framework of ACCVERSE.
The application itself is currently in private testing.
